# Navya Vempati — Data Engineer Portfolio

A responsive personal portfolio website with a modern dark-blue theme.

## Sections
- Introduction and profile
- About and technical skills
- Three illustrative data engineering portfolio builds
- Professional experience
- GitHub contact link

## Tech stack
HTML · CSS · JavaScript · GitHub Pages

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that publishes the static site. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. The workflow will deploy on pushes to `main`. After the first successful run, the site will be available at:

https://vempatinavya.github.io/navya-data-engineer-portfolio/

## Personalize before sharing
- Replace the illustrative project descriptions with links to your actual project repositories as you publish them.
- Add a resume PDF only when you are ready to make it public, then add its link to the page.
- Add a professional email or LinkedIn URL if you want visitors to contact you outside GitHub.

**Note:** The three project cards currently describe portfolio build concepts; they are not presented as verified production deployments.
